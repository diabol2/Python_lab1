# Лабораторная работа №1: Математический калькулятор и конвертер величин

Консольное приложение для вычисления математических выражений и конвертации величин. Для обеспечения высокой точности все внутренние расчеты выполняются с использованием модуля `Decimal`.

## Архитектура и логика работы

### Математический калькулятор (`calc`)
Вычисление математических выражений работает в три этапа:
1. **Токенизация и обработка унарных знаков:** Входная строка разбивается на числа и операторы. Алгоритм умеет обрабатывать и преобразовывать любые цепочки унарных знаков (например, `----5 + 5` корректно преобразуется в `5 + 5`).
2. **Построение ОПН:** Выражение переводится в Обратную польскую нотацию.
3. **Вычисление стеком:** Итоговое выражение вычисляется последовательным проходом с использованием стека.

### Конвертер величин (`convert`)
Поддерживает работу со следующими единицами измерения:
* **Длина:** миллиметры (`mm`), сантиметры (`cm`), дециметры (`dm`), метры (`m`), километры (`km`).
* **Масса:** граммы (`g`), килограммы (`kg`).
* **Температура:** Фаренгейт (`f`), Цельсий (`c`), Кельвин (`k`).

**Принцип работы:** 
Для мер длины и массы используется приведение к «базовой единице» (миллиметры и граммы). Исходное значение приводится к базе, а затем переводится в целевую единицу. Конвертер проверяет совместимость типов и не позволяет переводить массу в длину. 
Для температур базовой точкой является шкала Цельсия. Также добавлена проверка на физическую корректность — программа выдает ошибку, если значение находится ниже абсолютного нуля.

## Установка и настройка

Чтобы репозиторий появился у вас на компьютере, введите в командной строке (в той папке, в которой хотите, чтобы лежал репозиторий):

```bash
git clone https://github.com/diabol2/Python_lab1
```

Установите необходимые зависимости
```bash
pip install -r requirements.txt
pip install -e .
```

## Инструкция по использованию

Для вызова справки, где расписана основа работы приложения, используйте команду `--help`:

```bash
python3 -m toolkit --help
```

### Модуль калькулятора (`calc`)
Математическое выражение необходимо передавать в кавычках `""`. Поддерживаются операторы: `+`, `-`, `*`, `/`.

Пример запуска:
```bash
python3 -m toolkit calc "----5 + 5"
```

### Модуль конвертера (`convert`)
Пример перевода мер длины:
```bash
python3 -m toolkit convert 1000 --from mm --to m
```

## Автоматическое тестирование

Архитектура тестов включает в себя:
* **Положительные тесты:** проверка корректности стандартных расчетов и правильных конвертаций.
* **Отрицательные тесты:** проверка обработки ошибок (деление на ноль, несовместимые типы конвертации, значения ниже абсолютного нуля и другие).
* **Тесты CLI:** проверка работы консольного интерфейса, перехвата потоков вывода и кодов возврата.

Запуск тестов выполняется из корневой папки проекта с помощью команды:

```bash
pytest
```
